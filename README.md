Task 1: Responsive Landing Page

Web Development Internship @ Prodigy InfoTech

📝 Project Overview
This repository contains the code for Task 1 of the Prodigy InfoTech Web Development Internship. The objective was to build a responsive landing page with an interactive navigation menu that remains fixed at the top of the screen and changes styling based on user interaction (scrolling and hovering).

✨ Features
Fixed Navigation Bar: The menu stays visible at the top of the screen while scrolling.
Scroll Interactivity: The background color of the navigation bar changes dynamically when the user scrolls down the page.
Hover Effects: Navigation links change color when hovered over by the mouse.
Responsive Design: The layout automatically adjusts to fit both desktop and mobile screen sizes cleanly.

🛠️ Technologies Used
HTML5: Used for structuring the web page and navigation menu.
CSS3: Used for styling, responsive design (media queries), and hover animations.
Vanilla JavaScript: Used to detect the scroll event and trigger the background color change.

🚀 How to Run the Project

1. Download or clone this repository.
2. Navigate to the folder containing the files.
3. Simply double-click the index.html file to open it in your default web browser. No server installation is required!
